`estel.BackendMismatchError` is no longer public (decision of the maintainer, 27 November 2026; Part IV, §22). Mixing arrays of two backends still raises the same error, a subclass of `TypeError` with the same message saying how to fix it, as every other error of ESTEL; catch it as `TypeError`. The class stays, internal, in `estel.backend._registry`. This is a major change because a public name is removed from `api/manifest.json`. No value changes.
