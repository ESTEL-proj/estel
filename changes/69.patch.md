CI runs two tiers: pull requests run a fast tier (`make check`: the tests not marked `slow`, in float64 on PyTorch plus the tests marked `dtype` in float32, and the `jax_smoke` subset on JAX), with a time budget per test and per job; `main`, a nightly run and pull requests labelled `full-ci` run the full tier (`make check-full`: every test, both backends, both dtypes). Tests are as short as possible (golden rule 13, Part I §5.4, review rule C11).
