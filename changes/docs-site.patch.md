The skeleton of the user documentation, a Sphinx site in `docs/user/` for Read the Docs (`.readthedocs.yaml`): home, install, a quickstart executed at build time, the API reference generated from `api/manifest.json`, a first look at `docs/maths.md` with its formulas rendered, and contributing. `make docs` builds it with warnings as errors; the dependencies are in the new group `docs` of `pyproject.toml`. No public name or statistic changes.
