The renaming task (Q24 of Part IV, §23; decisions R-A02 to R-A11 and R-S08 of §22.5; issue #75): public names, arguments and values renamed, and one reduction method instead of three. No statistic changes. Old name → new name:

- `estel.DataClass` → `estel.Data` (R-A08); `Data1D` and `Data2D` unchanged.
- `estel.ScatteringPlan` → `estel.STPlan`, `estel.ScatteringFilters` → `estel.STFilters` (R-A04).
- `STOperator(norm="vanilla")` → `norm="none"`, `norm="store_ref"` → `norm="self"` (still the default), `norm="load_ref"` → `norm="ref"`; `STOperator.norm` returns the new values (R-A02).
- `STOperator(norm_batch_mean=...)` → `ref_batch_mean=...` (R-A02).
- `STOperator(compute_cross_matrix=...)` → `cross_matrix=...`; `compute_PS` unchanged (R-A05).
- `estel.functional.scattering(x, plan, filters, ref=None)` → `scattering(data, plan, filters, ref=None)` (R-A11).
- `STStatistics.iso()`, `STStatistics.angular_ft(harmonics)` and `STStatistics.scale_ft(harmonics, dj)` → one method, `STStatistics.reduce(*, iso=False, angular_fourier=False, angular_harmonics=None, scale_cosine=False, scale_harmonics=None, dj=None)` (R-A07, R-S08). It applies the selected reductions in the order of M-NORM, with the same mathematics; `angular_fourier` stays allowed without `iso`, `scale_cosine` needs `iso`, and reduced statistics are not reduced again. `stats.iso().angular_ft(h).scale_ft(k, dj)` becomes `stats.reduce(iso=True, angular_fourier=True, angular_harmonics=h, scale_cosine=True, scale_harmonics=k, dj=dj)`.
- Internal identifiers in American spelling (R-A03), for example `_crop_centre` → `_crop_center`, `_centred_frequencies` → `_centered_frequencies`, `lowpass_realisation` → `lowpass_realization`, `_parametrised_names` → `_parametrized_names`; prose stays British.

The file format of `STStatistics.save` changes with the renamed `norm` values, `ref_batch_mean` and the reductions: `SCHEMA_VERSION` is 2, and files of version 1 are not read (before 1.0.0). STL's names stay in the parity cases and fixtures; the parity tests map them to ESTEL's. Spec edits authorised on #75: the ESTEL names in docs/maths.md and Parts I to III of docs/transfer/ (STL's names kept, with ESTEL's first where both are meant); in Part IV, the rows R-A02 to R-A11 of §22.5 (R-A07 replaced by R-A07, R-S08) and the row Q24 of §23, deleted.
