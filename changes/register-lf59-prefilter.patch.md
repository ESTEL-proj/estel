Register, a revision of 25 November 2026 to the decisions of the same day on LF58 and LF59: the target of a synthesis is no longer pre-filtered to the Nyquist disk before its statistics. With `var` out of the synthesis loss, every statistic of the loss is blind beyond the disk, so filtering the target is no longer needed, and no Nyquist filter is applied to a target that is not periodic or has missing data, where a cut in Fourier space is not defined. Synthesis from maps is therefore the statistics of the maps, not pre-filtered, with the batch standardisation, then synthesis from statistics: still one code path. The pooled μ and σ are computed on the target as given. The Nyquist filter acts on the running field only: the band-limited start and the projection at each evaluation, with the cut of LF64. The 5 × 5 wavelets and the smoothing kernel, cropped in pixel space, respond slightly beyond the disk, so the S1–S4 of a target not filtered carry a small contribution from its corners that the running field cannot reproduce: LF59's task that measures the leak through these kernels measures this contribution too, and if it is not negligible the target can be filtered where the filter is defined. The cards stay `decision`. Documentation only: no change to `src/`, to any statistic or reference value.
