The orchestrator skill `/estel-master` is shared in the repository, in `.claude/skills/estel-master/SKILL.md`, so that every maintainer's Claude Code session can start an orchestrator session on ESTEL. The agents that write code run `make check`; the orchestrator re-runs it only on a state no agent checked, and relies on CI once the work is pushed. A session's handover stays in that user's Claude Code memory, never in a pull request. Tooling for agents only: no change to `src/`, to any statistic, public name or reference value.
