CI hardening (review rule E5), at the maintainer's request: every action in `.github/workflows/` is pinned to a full commit SHA with its version as a comment, every `actions/checkout` sets `persist-credentials: false`, and the workflow keeps a top-level `permissions: contents: read` (no job needs more). `.github/dependabot.yml` updates the pinned actions weekly, grouped in one PR. `make check` runs the new `tools/check_workflows.py`, which fails on an unpinned `uses:`, a pin without a version comment, a checkout that persists credentials, or a workflow without a top-level `permissions:` block. CI and tooling only: no public name or reference value changes.
