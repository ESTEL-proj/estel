Syntheses on PyTorch compute the loss and its gradient once per point: the L-BFGS driver, which runs one `LBFGS.step` per iteration, no longer evaluates again the point each step opens at, which the line search before had already evaluated. A synthesis takes about half the time (0.55 of it on a 64 × 64 field, 30 iterations); its iterates, losses, fields and counts are unchanged, bit for bit (finding P6-01 of the final review of step 1).
