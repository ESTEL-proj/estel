The trials of P3 on tensor products (T3.5, #128), each kept only if the benchmark shows its gain. Kept: `conv_axes` on PyTorch filters along one axis with `conv2d`, the batch as a spatial axis, instead of the slow `conv1d` (forward ÷11, forward with gradient ÷8 on the 32 × 32 × 16 case); `pad` on PyTorch by slices and one concatenation instead of `index_select`; the planar filtering of a real array in one real call with the real and imaginary kernels stacked. Every value stays within the parity tolerance; no public name or reference value changes.
