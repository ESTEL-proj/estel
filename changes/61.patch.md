Add the planar wavelet banks and the anti-aliasing kernel H (task T2.2, Part II §12.5), built in NumPy float64 in the private module `estel.wavelets._banks`: `bump_steerable_2d` (maths.md M-WAV-2D), `bump_steerable_1d`, with its conjugate for L = 2 (M-WAV-1D), and `smoothing_kernel_H` (M-H, M-H-1D), ported from STL `master` and `2D+1D`. The kernels equal STL's on the parity fixtures `bump_steerable_kernel_2d` and the new `bump_steerable_kernel_1d`; H equals STL's bit for bit, which the masked 1D downsampling needs where a fraction of invalid input equals τ = 0.5 exactly. `Data1D` and `Data2D` gain the geometry hooks `_conv` (padding and correlation, M-CONV-2D) and `_downsample` (M-DOWN, normalised as in M-DOWN-MASK, with masked pixels never read), and the masks parity test now uses ESTEL's own H. STL's kernels do not satisfy the Littlewood–Paley condition exactly, and 1.0.0 does not test it (LF22). No public name or reference value changes.
