In 2D, including the 2D blocks of tensor products, tests, benchmark cases and parity cases use L ≤ 4, the default (golden rule 13, issue #133). A new check of `make check`, `tools/check_orientations.py` (target `orientations` of `check-tools`), fails on an integer L above 4 in `tests/`, `bench/` and `tools/stl_parity/cases/` unless its line carries `# allow-large-L: #<issue>`, the issue where a human approved it. The library still accepts any L. No public name or reference value changes.
