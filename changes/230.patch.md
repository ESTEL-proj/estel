P5-01 of the final review: the HEALPix convolution reads each pixel once instead of twice. The internal L0 primitive `gather_weighted` accepts an index `(P, 1, M)` shared by the Q entries of each row, and the folded HEALPix tables keep one row of index for the real and the imaginary parts: on `healpix-masked-64` the forward pass takes ×0.67, the forward pass with the gradient ×0.57, the memory of the computation ×0.85. On JAX a shared index is contracted by `einsum`, since XLA on CPU miscompiles its broadcast form in float32 under `jax.jit`. The statistics are unchanged (bit for bit on PyTorch, to rounding on JAX); the gradient changes by rounding. Internal only: no public name or reference value changes.
