Add the experimental JAX backend of the L0 primitives (T1.3): `estel.backend.jax._primitives.JaxBackend` implements every primitive of `estel.backend._protocol` except `lbfgs`, which raises `NotImplementedError` until step 2 (LF1). 64-bit dtypes need JAX's `jax_enable_x64`, which the backend never switches itself; `deterministic` sets `--xla_gpu_deterministic_ops` in `XLA_FLAGS` before JAX starts. The test suite now runs on both backends (`ESTEL_TEST_BACKEND=torch|jax`), `make check` runs both, tier 0 runs one per job, and `jax>=0.5` is an optional extra (`estel[jax]`). Internal only: no public name changes; JAX becomes selectable with `set_backend` in T1.5.
