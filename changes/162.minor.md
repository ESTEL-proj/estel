Syntheses with the 2D power spectrum (maths.md M-SYN-OPS, M-SYN-LOSS): `synthesize_from_maps` puts the spectrum in its loss by default (`compute_PS=None` or True), as STL's user-level function for periodic fields, with J and the number of bins passed to both operators (the smaller of the two fields' default numbers of bins); `compute_PS=False` leaves it out, and its values do not change. `synthesize_from_stats` accepts statistics that hold the spectrum and puts it in the loss, its running operator taking J, the number of bins and J_min of the statistics (OP-76). The manifest of a run records the spectrum (`spectrum`), and `resume_from` refuses a checkpoint of a run with other settings of the spectrum. No public name changes.
