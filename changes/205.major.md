`SpectrumOperator` and `estel.functional.spectrum` are removed: ESTEL computes the power spectrum within `STOperator` only (`compute_PS`, `n_bins`, `Jmin`, `spectrum_method`), over the band set by the operator's J, as before. Compute the spectrum alone with `STOperator(data, J, compute_PS=True)` and `select("PS")`. Files: schema version 9; files of version 8, those written by `SpectrumOperator` among them, are refused. No value of `STOperator` changes. This is a major change because public names are removed from `api/manifest.json`.
