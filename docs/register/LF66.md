## Feature

In tensor products, only the fully low-passed field (the low-pass filter in every block) enters S3 and S4, in every position; the mixed scales (the low-pass filter in some blocks, a wavelet in another) stay out of S3 and S4, as in 1.0.0. On a single block it is LF6's set

## Why

LF6's set adds 38.2 % to the 2D+1D case of the STOC deliverable and 111.8 % to 2D+1D+1D (S4 more than doubles); this set adds 2.4 % and 0.9 %

## Builds on (reserved in 1.0.0)

the index sets of the plan
