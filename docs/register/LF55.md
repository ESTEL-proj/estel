## Goal

A 2D array given as 1D data is read as batch elements or as channels, as the user says; without that, it is read as in 1.0.0, with a warning that says how to choose.

## Inputs

maths M-DATA-1D ("Shape"), OP-29 (§2.6); M-DATA-2D and M-DATA-TENSORPROD ("Shape"), which read a leading axis the same way; Part II §12.4 (`Data`, `Data1D`); Part I §2.3 ("One way to say it").
Modules: `src/estel/data/_base.py` (`_promote`), `src/estel/data/_cartesian.py` (`DataCartesian._accepted_shapes`, `Data1D`), `api/manifest.json`, `tests/geometry/`.

## Tasks

1. [human] The keyword that names the first axis of a 2D array (batch or channel) in `api/manifest.json`; M-DATA-1D and OP-29 in `docs/maths.md`; and whether the 3D arrays of `Data2D` and the arrays of tensor products with one leading axis, read the same way, get the keyword too.
2. `Data1D` reads the keyword; without it, a 2D array is read as `(1, Nc, N)` and a `UserWarning` names the keyword; `changes/<PR>.minor.md`.

## Done when

A `(4, 32)` array read as batch gives the statistics of the `(4, 1, 32)` array, read as channels those of `(1, 4, 32)`, both without warning; without the keyword, the 1.0.0 values and a `UserWarning` that names it; 1D and 3D arrays unchanged, without warning; the reference tests pass without regeneration.

## Feature

1D data given as a 2D array: its axes read explicitly, with a warning

## Why

a 2D array given as 1D data is read as (Nc, N), not (Nb, N), without warning (OP-29)
