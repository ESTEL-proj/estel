## Goal

`STStatistics.to_xarray()` returns the statistics as an xarray `Dataset`, one variable per family with named axes, for inspection with xarray's tools.

## Inputs

Part II §12.7 (the rows `.full_grid`, `.select` and its axis names, `.to_xarray()`); Part I §2.4 (import rules).
Modules: `src/estel/statistics/_statistics.py`, `src/estel/statistics/_grid.py`, `pyproject.toml` (an optional extra), `api/manifest.json`, `tests/statistics/`.

## Tasks

1. [human] `STStatistics.to_xarray()` in `api/manifest.json`: a `Dataset`, one variable per family, the axes of `select` plus a batch axis; `xarray` as an optional extra.
2. The method, importing `xarray` lazily; its tests; `changes/<PR>.minor.md`.

## Done when

For a 2D, a 1D, a tensor-product and a HEALPix operator, each variable equals `full_grid(family)` in NumPy, NaN included, with the axis names of `select`; reduced statistics carry the reduced names (`dl`, the prefix `h`, `k`, `a`, `b`); without xarray, an `ImportError` says how to install it; it runs on both backends; each test runs in under 1 s.
