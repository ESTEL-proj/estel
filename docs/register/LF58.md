## Goal

A synthesis gives the same trajectory and the same result whether its target is given as maps or as the statistics of those maps: one meaning of `mean_field`, one standardisation, one loss and one form of the result; for every geometry with syntheses (periodic planar data in 1.0.0, T6.1).

## Brief

- **Question 1. What `mean_field` means, and the standardisation it implies** (OP-72; the definition to write in `docs/maths_step2.md`).
  - (a) an ensemble target: the target maps are draws of one process; each is standardised on its own (M-STD), as the statistics API does; the loss compares batch means; the result is de-standardised with the pooled μ_c and σ_c of the per-map moments, σ_c² = mean_b(σ_b² + (μ_b − μ_c)²); from maps is then from the statistics of the pre-filtered maps, one code path; nothing changes for one target map;
  - (b) the same concept with the pooled standardisation of from-maps (M-SYN-TARGET) everywhere: the statistics API gains a batch standardisation, an API addition, which from statistics then requires;
  - (c) the two rules kept, and documented.
  - **Recommendation:** (a): the two entries become equal by construction, with no new API.
- **Question 2. The normalisation of the loss** (OP-71).
  - (a) no division, from statistics as from maps;
  - (b) the loss divided by its number of real terms, for both, which changes what the L-BFGS tolerances (10⁻¹², 10⁻¹⁵) mean.
  - **Recommendation:** (a): the target's Nb has no role in the loss; a scale of the loss belongs with its weights (LF56, step 2b).
- **Question 3. The channel axis of the result** (OP-75).
  - (a) removed when Nc = 1, from both entries, as the batch axis is when `nbatch` = 1;
  - (b) kept when the target had one, which the statistics must then record;
  - (c) never removed.
  - **Recommendation:** (a): one rule, by size, for both axes, and no state in the statistics.

## Feature

One loss function for both entries of the syntheses, from maps and from statistics, whatever the path followed: one normalisation of the loss, one standardisation and one form of the result

## Why

the loss is divided by Nb from statistics only (OP-71), the two entries standardise differently (OP-72), so one target gives two trajectories, and they remove the channel axis of the result under different rules (OP-75)
