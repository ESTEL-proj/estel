# The ESTEL specification

From draft 0.4 (12 November 2026), this folder and [`docs/maths.md`](../maths.md) are the reference specification of ESTEL step 1. They are edited here, in the repository; there is no other copy to export from.

## Files

| File | Content |
|---|---|
| [`overview.md`](overview.md) | Overview and preamble: what ESTEL is, and the contents of the whole specification |
| [`part1.md`](part1.md) | Part I — General rules (§1–§8) |
| [`part2.md`](part2.md) | Part II — Step 1: transfer from STL (§9–§15) |
| [`part3.md`](part3.md) | Part III — Step 2: later developments (§16–§20) |
| [`part4.md`](part4.md) | Part IV — Review and decisions (§21–§24) |
| [`appendices.md`](appendices.md) | Appendices: glossary, references, version notes |
| [`../maths.md`](../maths.md) | The mathematics of step 1, with the `M-` IDs that `estel._spec` implements |

## How they change

- These files are protected paths (CODEOWNERS). They change only through pull requests that a maintainer requests and merges.
- Agents never change them on their own initiative. When an agent finds the specification ambiguous or wrong, it opens an issue (`AGENTS.md`, golden rule 10).
- The history of the specification is the git history of these files.
- The original design document, from which drafts up to 0.3 were exported, is archived and no longer updated.
