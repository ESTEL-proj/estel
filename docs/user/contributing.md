# Contributing

Most changes to ESTEL are written by coding agents and reviewed by its maintainers; the same rules
hold for every contributor. Start with
[`AGENTS.md`](https://github.com/ESTEL-proj/estel/blob/main/AGENTS.md): the golden rules, the
layers of the code, the numerical rules, the protected paths and the commands, `make check` first.
The guides it points to are in
[`docs/agents/`](https://github.com/ESTEL-proj/estel/tree/main/docs/agents): the architecture,
the rules of the backends, differentiation, testing, storage, and the review rules.

`make docs` builds this documentation, with every warning an error, as Read the Docs does.
